# 1. The Most Precise Useful Definition

An LLM is fundamentally a parameterized function that assigns probabilities to sequences of tokens.

Suppose a sequence is:

$$ x_1,x_2,\ldots,x_T $$

where:

\(x_i\) is a token
\(T\) is the sequence length
\(\theta\) represents the model parameters

The model represents:

$$ P_\theta(x_1,x_2,\ldots,x_T) $$

For an autoregressive language model, we can factor this probability using the chain rule:

$$ \boxed{ P_\theta(x_1,\ldots,x_T) = \prod_{t=1}^{T} P_\theta(x_t|x_1,\ldots,x_{t-1}) } $$

This equation is the foundation of everything that follows.

<br>

# 2. What Does This Equation Actually Say?

Take:

```
The cat sat on the mat
```

The model doesn't fundamentally treat this as one indivisible sentence.

Instead, it models:

P("The")

P("cat" | "The")

P("sat" | "The cat")

P("on" | "The cat sat")

P("the" | "The cat sat on")

P("mat" | "The cat sat on the")

The probability of the entire sequence is:

$$ P(\text{The}) \times P(\text{cat}|\text{The}) \times P(\text{sat}|\text{The cat}) \times \cdots $$

Therefore:

$$ \boxed{ \text{Generation = repeated next-token prediction} } $$

This is the first major mental model.

That's useful initially, but technically incorrect.

LLMs operate on tokens.

an entire word<br/>

common multi-character sequences<br/>
<br/>
For example, conceptually:
<br/><br/>

"Hello world!"

might become:

["Hello", " world", "!"]

The exact result depends on the tokenizer.

So instead of thinking:

sentence → words

think:

text → tokens

Mathematically:

$$ \text{text} \rightarrow x_1,x_2,\ldots,x_T $$

where:

$$ x_i \in \{0,\ldots,V-1\} $$

and \(V\) is the vocabulary size.

# 5. Why Token IDs?

Suppose the vocabulary contains:

cat<br/>
dog<br/>
banana<br/>
quantum<br/>

The tokenizer assigns each token an integer ID:

cat      → 1024<br/>
dog      → 2048<br/>
banana   → 3987<br/>
quantum  → 7812<br/>

These IDs are identifiers, not meaningful numerical quantities.

For example:

dog = 2048<br/>
cat = 1024<br/>

doesn't mean:

$$ \text{dog} > \text{cat} $$

in any semantic sense.

The integers are simply labels.

So we need another transformation.


# 6. Token IDs → Embeddings

The model contains an embedding matrix.

Let:

$$ E\in\mathbb{R}^{V\times d} $$

where:

\(V\) = vocabulary size<br/>
\(d\) = embedding dimension

For example:

$$ V=100000 $$

and:

$$ d=4096 $$

Then:

$$ E\in\mathbb{R}^{100000\times4096} $$

Every token ID corresponds to one row.

Conceptually:

token ID
   ->
embedding lookup
   ->
vector

For example:

cat
 ↓
[0.21, -0.73, 0.41, ..., 0.18]

Mathematically:

$$ x_i \rightarrow E[x_i] $$

The token ID is discrete.

The embedding is continuous.



# 7. Why Do We Need Embeddings?

# 8. But Embeddings Alone Aren't Enough

Suppose we have:
```

```
Both contain almost exactly the same words.

A simple collection of token embeddings doesn't inherently understand:

# 9. Transformer: The Context-Mixing Machine

A Transformer takes token representations and repeatedly transforms them.

Conceptually:

```

        ↓
Context interaction
        ↓
New representations
        ↓
Context interaction
        ↓
New representations
        ↓
...
        ↓
Contextual representations
```

The primary mechanism that allows tokens to interact is:

$$ \boxed{\text{Self-Attention}} $$
# 10. WTF Is Attention?

Consider:

The animal didn't cross the street because it was tired.

The token:

<h2>it</h2>
needs to interact with earlier tokens to understand what it refers to.

Attention gives each token a mechanism to determine:

Which other tokens are relevant to my representation?

That's the core intuition.

11. Query, Key, Value

For each token representation \(X\), the Transformer computes:

$$ Q=XW_Q $$ $$ K=XW_K $$ $$ V=XW_V $$

These are:

Q = Query
K = Key
V = Value

A useful mental model:

Query
"What information am I looking for?"

Key
"What information do I contain?"

Value
"What information should actually be retrieved?"

Attention scores are computed using:

$$ S= \frac{QK^T}{\sqrt{d_k}} $$

Then:

$$ A=\operatorname{softmax}(S) $$

And finally:

$$ \boxed{ \operatorname{Attention}(Q,K,V)=AV } $$

Don't memorize this blindly.

Later we'll derive every piece.

For now, understand the pipeline:
```

Q + K
   ↓
relevance scores
   ↓
softmax
   ↓
attention weights
   ↓
weighted combination of V

```
# 12. Why \(QK^T\)?

This is one of the most important questions we'll eventually answer mathematically.

Suppose:

$$ Q_i $$

represents what token \(i\) is looking for.

And:

$$ K_j $$

represents what token \(j\) offers.

Their dot product:

$$ Q_iK_j^T $$

measures their compatibility.

So:

$$ QK^T $$

creates a matrix where every token can have a relevance score with every other token.

If there are \(T\) tokens:

$$ QK^T\in\mathbb{R}^{T\times T} $$

That \(T\times T\) interaction matrix is the source of the famous attention complexity:

$$ O(T^2) $$

We'll dig deeply into that later.

# 13. Causal Attention

For autoregressive generation, the model cannot look into the future.

Suppose:

The cat sat on the mat

When predicting:

mat

the model should only use:

The cat sat on the

It must not use:

mat

or anything after it.

Conceptually:

             The cat sat on the mat
```

The          ✓   ✗   ✗   ✗   ✗   ✗
cat          ✓   ✓   ✗   ✗   ✗   ✗
sat          ✓   ✓   ✓   ✗   ✗   ✗
on           ✓   ✓   ✓   ✓   ✗   ✗
the          ✓   ✓   ✓   ✓   ✓   ✗
mat          ✓   ✓   ✓   ✓   ✓   ✓


```
This is implemented using a causal mask.

The model therefore respects:

$$ P(x_t|x_1,\ldots,x_{t-1}) $$

instead of cheating with future information.

# 15. Hidden Representations

After passing through the Transformer, each token has a contextual representation.

Conceptually:

```
The   → h₁
cat   → h₂
sat   → h₃
on    → h₄
the   → h₅
```

where:

$$ h_i\in\mathbb{R}^{d} $$

These aren't merely the original token embeddings anymore.

They contain information influenced by context.

For generation, we're primarily interested in the representation at the final position:

$$ h_T $$
# 16. Hidden State → Logits

The model then projects the final hidden state into vocabulary space.

Conceptually:

$$ z=h_TW_U+b $$

where:

$$ z\in\mathbb{R}^{V} $$

If:

$$ V=100000 $$

then the model produces 100,000 numbers.

Something conceptually like:

```
mat       → 8.7
floor     → 6.2
chair     → 4.1
banana    → -1.7
quantum   → -2.3
...
```

These values are called:

$$ \boxed{\text{Logits}} $$


This distinction is extremely important.

Suppose:

mat       → 8.7
floor     → 6.2
chair     → 4.1

Those numbers:

can be negative
can be positive
don't sum to 1
aren't probabilities

They're simply scores.

Higher score generally means:

The model assigns greater preference to this token.

We need to transform those scores into probabilities.



$$ \boxed{ P(x_{T+1}|x_1,\ldots,x_T) } $$


# 17. Generation Is a Loop

The core algorithm is conceptually:

```
let tokens = tokenize(prompt);

```

```TS
while (!shouldStop(tokens)) {
  const logits = model(tokens);

  const probabilities = softmax(logits);

  const nextToken = decode(probabilities);

  tokens.push(nextToken);
}
return detokenize(tokens);
```


This is not production LLM inference code.

It's a mental model.

Real inference engines are much more complicated and optimized.

But notice something important:

The model's job is primarily:

model(tokens) → logits

The generation system handles:

```
logits
 ↓
probabilities
 ↓
decoding
 ↓
next token
```
# 18. Autoregressive Generation Mathematically

At every generation step:

$$ x_{t+1} \sim P_\theta(x_{t+1}|x_1,\ldots,x_t) $$

Then:

$$ x_{t+2} \sim P_\theta(x_{t+2}|x_1,\ldots,x_t,x_{t+1}) $$

Then:

$$ x_{t+3} \sim P_\theta(x_{t+3}|x_1,\ldots,x_t,x_{t+1},x_{t+2}) $$

And so on.

Therefore:

$$ \boxed{ \text{Generated sequence} = \text{repeated conditional sampling} } $$

# 20. The Entire Model in One Sentence

If someone asks:

<h4>"What is an LLM?"</h4>

A technically useful answer is:

```
An autoregressive LLM is a parameterized neural network that maps a sequence of tokens to a probability distribution over the next token, and generation repeatedly applies that function while extending the sequence.
```

Mathematically:

$$ f_\theta(x_1,\ldots,x_t) \rightarrow P_\theta(x_{t+1}|x_{\leq t}) $$

Everything else is machinery that makes this function powerful and efficient.
